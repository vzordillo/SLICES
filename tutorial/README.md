# Examples Directory

Example scripts demonstrating SLICES usage.

## Structure

### `basic/`
Basic usage examples:
- `2.1structure2SLICES_SLICES2structure.py` - Basic encoding and decoding

### `advanced/`
Advanced usage examples:
- `2.2data_augmentation_get_canonical_slices.py` - Data augmentation and canonical SLICES

## Sample Files

- `NdSiRu.cif` - Example crystal structure file
- `Sr3Ru2O7.cif` - Example crystal structure file

## Usage

```bash
# Run basic example
python examples/basic/2.1structure2SLICES_SLICES2structure.py

# Run advanced example
python examples/advanced/2.2data_augmentation_get_canonical_slices.py
```
