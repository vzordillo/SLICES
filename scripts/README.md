# Scripts Directory

This directory contains utility scripts for SLICES.

## Structure

- **`benchmarks/`** - Benchmarking scripts
- **`tests/`** - Testing scripts

## Scripts

### Benchmarking
- `benchmarks/encode_decode_orbv3_benchmark.py` - ORBv3 encoding/decoding benchmark
- `test_improved_decoding.py` - Test improved decoding on dataset

### Testing
- `run_tests.py` - Run test suite
- `validate_installation.py` - Validate installation
- `verify_baseline.py` - Verify baseline functionality

### Utilities
- `benchmark.py` - General benchmarking utilities
- `git_checkpoint.sh` - Git checkpoint script
